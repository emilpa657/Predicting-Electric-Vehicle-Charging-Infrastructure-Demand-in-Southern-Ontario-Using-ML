# Predicting-Electric-Vehicle-Charging-Infrastructure-Demand-in-Southern-Ontario-Using-ML

The global shift toward sustainable transportation has significantly increased the adoption of electric vehicles (EVs). Governments worldwide, including Canada, are promoting EV usage to reduce carbon emissions and dependency on fossil fuels. Southern Ontario, being one of the most populated and economically active regions in Canada, has witnessed a rapid increase in EV adoption. 

However, the development of EV charging infrastructure has not kept pace with this growth. Insufficient and uneven distribution of charging stations can lead to range anxiety among EV users and hinder further adoption. 

This project focuses on predicting the demand for EV charging infrastructure in Southern Ontario using machine learning techniques. By analyzing factors such as population density, EV registrations, and existing charging stations, the project aims to identify areas requiring infrastructure expansion. 

# Problem Statement 

With the rapid increase in EV adoption, the current charging infrastructure is insufficient and unevenly distributed across Southern Ontario. This creates challenges for EV users and policymakers. 

The main problem addressed in this project is: 

How can we predict future demand for EV charging stations to support efficient infrastructure planning? 
# Objectives 

The objectives of this project are: 

To analyze EV growth trends in Southern Ontario 

To identify key factors influencing charging infrastructure demand 

To build machine learning models for demand prediction 

To highlight high-demand regions for future infrastructure development 
# Literature Review 

Several studies have explored EV adoption and infrastructure planning. Research indicates that factors such as population density, income levels, and urbanization significantly influence EV usage. 

Machine learning techniques, including Linear Regression and Random Forest, have been widely used for predictive modeling due to their ability to handle complex datasets. 

Previous studies have also used Geographic Information Systems (GIS) for mapping charging station distribution. However, limited work has been done specifically for regional prediction in Southern Ontario, which this project aims to address.
